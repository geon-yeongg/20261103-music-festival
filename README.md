# FREQ! 2027 — 인디 뮤직 페스티벌 웹사이트

첨부된 레트로 음악 포스터의 청록·주황·노랑·크림 계열을 참고하여 만든 반응형 **가상 행사** 안내·신청 사이트입니다.

## 시작하기

1. ZIP 파일을 **압축 해제**합니다.
2. `index.html`을 크롬 또는 엣지에서 엽니다.
3. 상단 메뉴로 섹션을 이동하고 **전체 일정 보기 / 전체 프로그램 보기** 버튼을 눌러 팝업을 확인합니다.
4. **티켓 예매**를 누르면 별도의 `booking.html`로 이동합니다.
5. 날짜와 수량을 선택하고 신청자 정보를 입력한 뒤 **데모 티켓 신청하기**를 눌러 결과 팝업을 확인할 수 있습니다.

인터넷 없이도 이미지·스타일·스크립트가 작동하도록 필요한 리소스가 모두 포함되어 있습니다.

## 파일 구성

```text
indie_wave_festival/
├── index.html          메인 행사 안내 페이지
├── booking.html        별도의 티켓 신청 시연 페이지
├── css/
│   └── style.css       전체 디자인, 반응형 스타일, 주석
├── js/
│   ├── main.js         라인업 필터·날짜 탭·팝업 제어
│   └── booking.js      수량 계산·입력 검사·신청 결과 팝업
├── assets/
│   ├── hero-guitar.png, record.png, live-stage.png
│   ├── artist-*.png    아티스트별 독창적인 일러스트 6장
│   ├── *.svg           해당 그림의 벡터 원본
│   └── favicon.svg
└── README.md
```

## 주요 기능

- PC / 태블릿 / 스마트폰 대응 반응형 디자인
- 아티스트 카드 6개 및 날짜별 라인업 필터 (전체 / 토 / 일)
- 공연 타임테이블 토·일 날짜 전환
- **전체 일정 보기** 클릭 → 2일 전체 일정 팝업
- **전체 프로그램 보기** 클릭 → 5개 프로그램 상세 팝업
- 티켓 예매 버튼 → 별도 `booking.html` 이동
- 1일권 / 2일 통합권 선택, 1~4매 수량 선택 및 합계 자동 계산
- 이름 / 휴대전화 / 이메일 입력 검사, 동의 체크, 결과 팝업
- 이용 안내 FAQ, 모바일 내비게이션 및 하단 예매 버튼

## 수정 방법

- **행사 일정 / 아티스트별 시간:** `js/main.js`의 `festivalSchedule` 값과 `index.html`의 라인업 정보를 함께 수정
- **티켓 가격:** `js/booking.js` 상단의 `ticketTypes` 수정
- **색상:** `css/style.css` 맨 위의 `:root` 변수 수정
- **사진/그림:** `assets` 폴더 파일 교체 후 HTML의 `<img src="...">` 경로 수정
- **행사 정보:** `index.html`, `booking.html` 내 텍스트 수정

이 사이트의 페스티벌·장소·아티스트·일정은 **디자인 시연을 위한 가상 정보**입니다.
결제, 티켓 발급, 예약 시스템 서버, 이메일 발송, 데이터베이스 저장은 **구현되어 있지 않습니다**. 입력한 내용은 결과 팝업에만 잠시 표시되며 외부로 전달되지 않습니다.
실제 예약 서비스로 운영하려면 개인정보 처리 및 보안, 서버·데이터베이스, 결제 연동을 별도로 개발해야 합니다.
